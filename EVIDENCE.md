# Evidence Framework for Zanistarast

This document defines the proof structure of the Zanistarast project.

Its purpose is to convert philosophical claims into:

- formal statements
- measurable variables
- simulation tests
- falsification conditions

Without this structure, the framework remains conceptual.
With this structure, it becomes testable.

---

## 1. Core Principle

Zanistarast must be evaluated through four layers:

1. Claim
2. Mathematical Form
3. Simulation Test
4. Falsification Condition

---

## 2. Evaluation Matrix

| Layer | Claim | Mathematical Form | Simulation Test | Falsification Condition |
|------|------|------|------|------|
| Core Law | All systems operate through information-based control | System = Core + Control + Interaction | Remove control layer and observe collapse/stability loss | If systems remain equally stable without control |
| Hebûn | Being is a stable pattern of witnessing | V = Interaction(P, W) | Track pattern persistence and variance over time | If stable being emerges without witnessing |
| Zanabûn | Knowledge is coherent multi-agent witnessing | K = Mean(Wi), Truth ~ low variance | Measure coherence and convergence among agents | If incoherent witnessing yields stable truth |
| Mabûn | Stability emerges from circulation, not accumulation | Ri(t+1) = (1-a)Ri(t) + aR̄ | Compare circulation vs accumulation models | If no-circulation systems remain more stable |
| Rasterast | Adaptive governance increases system stability | D = f(H, E, S) | Compare adaptive councils vs rigid centralized systems | If rigid systems outperform adaptive governance |
| Simulation | Stability requires all four layers together | Integrated multi-agent model | Run full and ablated versions | If partial/random models outperform full model |

---

## 3. Claim Structure

Every Zanistarast paper must contain:

### A. Claim
A clear statement of what is being proposed.

### B. Formalization
A mathematical or structural expression of the claim.

### C. Test
A simulation, metric, or measurable process.

### D. Falsification
A condition under which the claim fails.

---

## 4. Required Metrics

The following metrics should be used across the project:

- Stability Index
- Variance of Witnessing
- Knowledge Coherence
- Gini Coefficient
- Collapse Rate
- Adaptation Speed
- Rights Violation Count

---

## 5. Scientific Rule

A Zanistarast claim is not considered complete unless it has:

- a formal statement
- a measurable variable
- a simulation path
- a falsification condition

---

## 6. Goal

The goal of this file is to ensure that Zanistarast is evaluated not only as a philosophy,
but as a testable scientific framework.
