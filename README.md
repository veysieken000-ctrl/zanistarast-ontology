## Hexa-Layer Structure

The model is built on six interacting layers:

1. Physical (Gravity)
2. Biological (Fitrah)
3. Cognitive (Consciousness)
4. Temporal (Renewal)
5. Spiritual (Conscience)
6. Social (Justice)

These layers form a unified system: **Hexa-Nizam**.

**A computational and theoretical framework integrating Being, Knowledge, Economy, and Governance.**

---

## 1. Overview

Zanistarast is a **multi-layered ontological system**:

1. **Hebûn** – Mathematical model of Being, Potential, Witnessing, and Interaction  
2. **Zanabûn** – Knowledge formation and validation  
3. **Mabûn** – Ethical and sustainable economic circulation  
4. **Rasterast** – Governance, ethical oversight, and systemic stability

> Each layer is fully defined mathematically and theoretically, enabling computational simulation, AI integration, and multi-agent modeling.
