# Zanistarast Paper Standard

This document defines the required structure for all papers.

All papers must follow this format to ensure:

- clarity
- comparability
- scientific consistency

---

## 1. Title

Clear and descriptive.

---

## 2. Abstract

Short summary including:

- what is proposed
- how it is tested
- main conclusion

---

## 3. Introduction

- problem definition
- gap in existing literature
- purpose of the paper

---

## 4. Core Claim

Clearly state:

> What is being claimed

---

## 5. Mathematical / Structural Model

- equations
- system definition
- variables

---

## 6. Theoretical Context

- link to existing scientific fields
- reference frameworks

---

## 7. Simulation / Test Model

- how the claim is tested
- experimental setup

---

## 8. Metrics

- which metrics are used
- how results are measured

---

## 9. Results / Expected Behavior

- what should happen
- system behavior

---

## 10. Falsifiability

Define:

> when the theory fails

---

## 11. Discussion

- interpretation
- limitations

---

## 12. Conclusion

- final statement
- contribution

---

## 13. Keywords

Standardized keywords

---

## 14. Mandatory Rule

A paper is incomplete if it lacks:

- mathematical model
- simulation plan
- falsification condition
